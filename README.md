# Модели за прогноза на акции, злато и крипто (v0.2)

Цел: **15–20% годишно** (≈1.2–1.5% на месец средно) с контролиран риск.

## Инсталация и стартиране

```bash
pip install -r requirements.txt
python test_no_leakage.py     # проверка, че няма изтичане на бъдеща информация
python run.py                 # реални данни, модел LightGBM
python run.py --model logreg  # базов модел за сравнение
python run.py --refresh       # изтегли свежи данни
```

Резултатите са в папка `reports/`:
- `summary.csv`: доходност, риск и точност по активи и за портфейла, сравнени с „купи и дръж“
- `monthly_returns.csv`: месечни резултати на портфейла
- `latest_signals.csv`: сигнал за днес (вероятност за ръст и размер на позицията)
- `equity_curve.png`: как растат 100 €

## Автоматично табло в GitHub Pages

GitHub Actions пуска моделите всеки ден в 22:30 UTC (01:30 българско време) и публикува таблото.

1. В GitHub създай ново **публично** хранилище (**New repository**), например `trading_models`.
2. Качи всички файлове от тази папка, включително скритата папка `.github`. Най-лесно е с git:
   ```bash
   cd trading_models
   git init && git add . && git commit -m "v0.1"
   git branch -M main
   git remote add origin https://github.com/<твоето-име>/trading_models.git
   git push -u origin main
   ```
   Ако качваш през сайта (**Add file → Upload files**), провлачи цялата папка, за да се качи и `.github`.
3. Отиди в **Settings → Pages → Build and deployment → Source** и избери **GitHub Actions**.
4. Отиди в таб **Actions → „Ежедневна прогноза и табло“ → Run workflow**. Първото пускане отнема около 5–10 минути.
5. Таблото се появява на `https://<твоето-име>.github.io/trading_models/`.

Ако някое пускане се провали, щракни върху него в таб **Actions** и виж червената стъпка.

Локален преглед на таблото: `python run.py && python dashboard.py`, после отвори `site/index.html`.

## Как работи

1. **data.py**: дневни данни от Yahoo Finance (SPY, GLD, BTC-USD, ETH-USD), кеширани в `data/`.
2. **features.py**: ~35 признака: моментум, волатилност, пълзящи средни, RSI, MACD, обем и състояние на пазара (SPY).
3. **model.py**: предвижда дали цената ще е по-висока след `HORIZON` дни (по подразбиране 5). Walk-forward: моделът се преобучава всеки месец само с минали данни, с embargo срещу изтичане.
4. **backtest.py**: сравнява няколко стратегии (в `config.STRATEGIES`):
   - **Тайминг**: в пазара само когато моделът е уверен в ръст, иначе кеш.
   - **Филтър** (основна): в пазара по подразбиране, излиза в кеш, когато моделът очаква спад.
   - **Без модел (риск-контрол)**: винаги в пазара, със същия контрол на риска. Показва дали моделът изобщо добавя стойност.
   - **Купи и дръж**: без нищо.
   Размерът на позицията се мащабира до целева волатилност и се смятат комисионни и спред.

Всички настройки са в `config.py`.

## Как да четем резултатите

- **Точност 51–55%** е нормален добър резултат. Над 60% почти винаги означава грешка.
- Гледай **Sharpe** (>0.8 е добре) и **макс. спад**, не само доходността.
- Моделът трябва да бие „купи и дръж“ поне по съотношение доходност/риск.
- Следваща стъпка е paper trading (без реални пари) поне 2–3 месеца.
